```css

```

# 24. RESPONSIVE DESIGN

Responsive design is NOT an afterthought.

Desktop:

- editorial composition
- asymmetric layout
- large visuals

Tablet:

- simplify overlays
- preserve hierarchy

Mobile:

- recompose rather than shrink
- verticalize diagrams
- simplify network systems
- intelligent image crops
- no horizontal overflow

Every phase involving visual changes must be checked on:

**desktop + tablet + mobile**
