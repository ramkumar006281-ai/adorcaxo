# Code Review

Before completing a task review the final changes.

Check:

- unnecessary files
- unnecessary dependencies
- duplicated logic
- dead code
- incorrect types
- security issues
- accessibility
- responsive behavior
- performance
- naming
- maintainability

Confirm that unrelated functionality was not modified.

Prefer the smallest clean change that completely solves
the requested problem.
