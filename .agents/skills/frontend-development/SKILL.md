# Frontend Development

Build clean, maintainable, and high-performance frontend components.

## Core Rules

1. **Design System Adherence**: Always reuse existing color tokens, typography scales, spacing units, and UI components before introducing new ones.
2. **Component Architecture**: Keep components focused, typed with TypeScript, and properly decomposed. Avoid bloated single-file monolithic components.
3. **Clean Code**: No magic numbers, no ad-hoc inline styles when classes/tokens exist, and preserve accessibility attributes.
4. **Framework Idioms**: Leverage Next.js App Router idioms, server vs client components appropriately, and image optimization.
