# Responsive Design

Responsive behavior is a first-class requirement.

Never design desktop first and assume mobile will work.

For every significant UI change evaluate:

## Mobile

375px
390px
430px

## Tablet

768px
820px
1024px

## Desktop

1280px
1440px
1920px

Check:

- content width
- typography
- spacing
- grids
- flex layouts
- images
- navigation
- buttons
- forms
- modals
- sticky elements
- overflow
- viewport height

Never introduce horizontal scrolling unless explicitly required.

Prefer fluid layouts over breakpoint-specific hacks.
